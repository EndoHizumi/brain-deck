# brain-deck のヘルプ

brain-deck は、PC のそばに置いて PC と一緒に使う、手元の PDA です。PC から外して持ち歩いても、時計、Todo、予定、読み物、メモなどが使えます。

このヘルプは、デーモン（版 {version}）に入っているものです。画面の右の 3 分の 1 をタップすると次のページ、左の 3 分の 1 で前のページ、真ん中で目次と文字の大きさです。本体キーの ← → とスペースでもめくれます。

# 基本の操作

## ホーム画面

アプリのアイコンが並んだ入り口です。アイコンをタップするとアプリに入ります。アプリが多いときはページが分かれ、下の帯か画面右の帯の、左右の三角でページを送ります。

## HOME

画面右の帯のいちばん上の HOME を押すと、どのアプリからでもホーム画面に戻ります。ホーム画面で HOME を押すと 1 ページ目に戻ります。端末モードからも HOME で抜けます。

## 画面右の帯

画面の右に印刷された帯（上から HOME、▲、▼、右と左の三角、決定、戻る、操作機能）も、タッチのボタンです。アプリごとに働きが違います。左手デバイスでは、レイヤーの切り替えなどに使います。

## ページ送り

Todo、カレンダー、ファイル、設定などの一覧は、下の帯の ▲ ▼ でページを送ります。触らずに 1 分たつと、最初のページに戻るものがあります。

## 長押し

押し続けると働くものがあります。
・Todo の項目：0.5 秒で、済んだ・まだを切り替える
・ファイルの行：0.8 秒で、消すかを聞く
・ストップウォッチ、カウンター、ポモドーロ：長押しで最初に戻す
・設定の「電源」：2 秒で、再起動か電源を切る

## 画面の明るさ

しばらく触らないと画面が暗くなり、さらに時間がたつと消えます。写真があれば、暗くする代わりに写真を出します（フォトフレーム）。暗いときや写真のときのタッチは、明るくするだけで、ボタンは押しません。本体のキーでも明るくなります。

## ふた

ふたを閉じると画面を消し、タッチを受け付けません。開けると元の画面に戻ります。閉じているあいだも、時計やタイマーは進みます。何もしないようにもできます（設定のアプリの「ふたを閉じたとき」）。

画面を裏返したタブレットの形のあいだは、本体のキーを使いません（裏になったキーが押されても、PC に送りません）。タッチは使えます。キーも使うときは、設定のアプリの「タブレットの形の本体キー」を「使う」にします。

## 文字を入れる

Todo を足す、時刻を合わせるときは、画面の下に入力欄が開きます。Brain のキーボードで打ち、決定で確定、戻るでやめます。後退で 1 字消し、← → でカーソルを動かします。

## 日本語を打つ

入力欄の題の横に［英数］か［かな］と出ているときは、日本語が打てます（uim-fep と Anthy）。
・文字切り替えを 1 回押す：かな と 英数 を切り替える（Ctrl+スペースでも）
・かな のとき：ローマ字で打つと ひらがな になり、スペースで漢字に変換。もう一度スペースで次の候補（下の行に一覧）。← → で文節を移り、シフト + ← → で文節の長さを変える。決定で確定
・戻る：変換中なら変換をやめる。変換中でなければ、欄をやめる
・変換中の形：F6 ひらがな、F7 カタカナ、F9 全角英数、F10 半角英数（端末モードのタッチのキー「日本語」のページにもあります）
初めて開くときは「日本語入力を準備しています…」と出て、3〜5 秒ほどで打てるようになります（打ったキーは覚えておいて、あとから入ります）。［英数］［かな］が出ないときは、日本語入力が使えません（設定のアプリの「日本語入力」）。

# アプリの使い方

## 左手デバイス

本体のキーとタッチのボタンを、PC のキーボードとして使います。押したキーは、設定のとおりのキーやショートカットになって PC に届きます。画面右の帯で、メニュー、コード、ブラウザなどのレイヤーに切り替えます。

## ダッシュボード

PC から送ったテキスト（ビルドの結果など）、時計、予定などをまとめて出します。PC で brain-deck text を使って書き換えます。

## Todo

一覧を見て、長押しで済んだことにします。「Todo 追加」で Brain のキーボードから足せます。日本語の項目は、PC の brain-deck todo add か設定 GUI で足します。Todo は Brain のデータが正で、PC から外していても失われません。

## カレンダーと天気

PC から受け取った予定と天気予報を出します。月の表示で日をタップすると、その日の予定が出ます。PC で brain-deck sync（または calendar sync、weather sync）を行うと新しくなります。

## 読む

PC で brain-deck read add で取り込んだ読み物（青空文庫、EPUB、Web のページなど）を読みます。左右のタップでめくり、真ん中で道具（一覧、目次、文字の大きさ、縦書き・横書き）です。読んでいた場所は、しおりとして覚えます。

## メモ

指かペンで手書きのメモを書きます。上の帯で、線の太さ、消しゴム、戻す、ページの追加、前・次を選びます。PC で brain-deck memo get で画像にして取り出せます。

## 電卓と道具

電卓は、タッチと本体のキーで計算します。道具には、ストップウォッチ、ポモドーロ、カウンター、在席ランプなどがあります。

## 入力とペン

入力はトラックパッドです。指で PC のマウスを動かし、タップでクリック、右の帯でスクロールします。ペンは、PC の絵のアプリにペンとして描きます。どちらも「マウス切替」で、キーボードとマウスの形にしてから使います（USB が数秒切れます）。

## 同期

「同期」のボタンで、PC の brain-deck sync が動きます（PC のショートカットの設定が要ります）。予定、天気、時刻などをまとめて新しくし、結果を画面の帯に出します。

## ファイル

Brain のファイル（ホーム、写真、メモ、読み物）を見ます。テキストと画像を開けます。開いているときに真ん中をタップすると、読み物、写真、背景画像に足せます。

## 本体と端末

本体のアプリには、電池、時刻合わせ、端末、タッチ調整などがあります。端末は、PC の端末か、Brain 自身のシェル（Brain にログイン）を選んで使います。HOME で抜けます。Brain 自身のシェルでは日本語も打てます（文字切り替えを 1 回押すと かな/英数。タッチのキーの「日本語」のページに、変換や候補のキーがあります）。

## 設定

明るさ、暗くなるまでの時間、フォトフレーム、画面の向き、読み物の文字の大きさ、ふたを閉じたときの動き、タブレットの形の本体キー、日本語入力（使う・使わない、方式）、時刻合わせを変えます。変えた値は「上書き」として Brain に置き、設定ファイルは書き換えません。「設定ファイルの値に戻す」で上書きを消します。「情報」には版、電池、SD カードの空き、PC とのつながり、最後に同期した時刻、「電源」には再起動と電源を切るボタン（2 秒押し続ける）があります。

# PC から外したとき

USB を抜くと、画面の上の帯に「PCなし」と出て、ホーム画面に切り替わります。つなぎ直すと、前の画面に戻ります。

使えるもの：ホーム画面、時計、Todo、受け取り済みの予定と天気、読み物、メモ、電卓、道具、ファイル、設定、ヘルプ。

休みになるもの：PC に送るキーとボタン、マウス、トラックパッド、ペン、PC の端末。押しても何も送らず、「PC につながっていません」と出ます。

外しているあいだは、早めに暗くして電池を持たせます（設定の「暗くなるまで（PC なし）」）。

# 困ったとき

## 電池

Brainux では、USB につないでも充電されません。充電は純正のファームウェアで行います。電池の電圧が 3.5 V を下回ると知らせ、3.4 V を下回るとデータを保存して電源を切ります。

## 画面が消えた

タッチか本体のキーで点きます。点かないときは、ふたを開け閉めしてみます。それでも点かなければ、PC で brain-deck restart を行います。

## タッチがずれる

本体のアプリの「タッチ調整」で、画面の十字を順に押します。

## PC にキーが届かない

画面を裏返したタブレットの形のあいだは、本体のキーを使いません。一度裏返して戻します。

画面の上の帯の「PC」が緑かを見ます。「PCなし」ならケーブルを、「給電のみ」なら PC の USB を確かめます。マウスやペンは「マウス切替」が要ります。

## 時刻が合っていない

時計が橙色で「時刻未設定」と出ているときは、PC につないで brain-deck time sync を行うか、設定のアプリの「時刻合わせ」で入れます。

## 設定を元に戻したい

設定のアプリの「設定ファイルの値に戻す」で、Brain で変えた値を消します。設定ファイルそのものは、PC の brain-deck config put で入れ直します。

## brain-deck が動かない

PC で brain-deck status と brain-deck logs を見ます。直らなければ brain-deck restart、それでもだめなら ssh brain かシリアルのコンソールから入ります（README の「困ったとき」）。更新のあとおかしければ、brain-deck update --rollback で前の版に戻します。
