# 15. 用語集

[目次に戻る](../architecture.md)

この資料、設定（docs/config.md）、コード、README で使う言葉。かっこの中は、設定やコードでの名前。

## brain-deck の言葉

| 言葉 | 意味 |
| --- | --- |
| **brain-deck** | プロジェクト全体の名前。また、PC のコマンドの名前（`cmd/brain-deck/`） |
| **lefthand** | Brain の上で動くデーモン（`/usr/local/bin/lefthand`、`lefthand.service`）。もとは「左手デバイス」の名前 |
| **左手デバイス** | 本体のキーとタッチを、PC へのショートカットのキー入力にする使い方。最初の目的。今はホーム画面のアプリの 1 つ（base などのレイヤー） |
| **設定 GUI** | ブラウザで開く設定の画面（`gui/`）。WebSerial で Brain とつなぐ |
| **レイヤー**（`layers`） | 割り当て（キー、セル、ソフトキー）の層。重ねて使い、上のレイヤーに書いていないものは下のレイヤーを使う（透過）。最初のものが base |
| **base** | いちばん下のレイヤー（`layers` の最初）。いつも重なりの底にある |
| **重なり**（stack） | 今、base の上に重ねているレイヤーの並び。いちばん上が「今のレイヤー」 |
| **透過** | 上のレイヤーに割り当てがなければ、下のレイヤーの割り当てを使うこと。`none` と書くと止まる |
| **割り当て**（`ActionSpec`、`Action`） | 1 つのキー、セル、ソフトキーに書くもの。送るキー、レイヤーの切り替え、マウス、ウィジェットなど |
| **セル**（`touch.cells`） | タッチの格子の 1 マス。`"列,行"` で書く。`span` で複数のマスにまたがれる |
| **格子**（`touch`、`Grid`） | レイヤーのタッチの区切り（`cols` × `rows`）。縦向き用は `touch_portrait` |
| **ソフトキー**（`soft_keys`、`touch.soft_areas`） | 画面の右の外、ベゼルに印刷されたボタンの帯（HOME、▲、▼、▶、◀、決定、戻る、操作機能）の区画。タッチパネルの生の座標で範囲を決める |
| **本体キー**（`keys`） | Brain のキーボードのキー。evdev の名前（`KEY_A` など。docs/keymap-pwsh2.md）で書く |
| **ウィジェット**（`widget`） | セルに、キーの代わりに出す情報や操作の部品（時計、Todo、予定、天気、電卓…） |
| **アプリ** | 3 つの意味がある：(1) ホーム画面のアイコン 1 つ（中身はレイヤー。`home.apps`）、(2) 大きなウィジェット（読み物のアプリ、設定のアプリなど）、(3) 自分で足すアプリ（`widget: app`）。[6. ウィジェットとアプリ](06-widgets.md) |
| **自分で足すアプリ**（`widget: app`） | `/var/lib/lefthand/apps/<名前>/` に置いたスクリプトの出力を描くウィジェット（フェーズ K5） |
| **ホーム画面**（`home`） | アプリのアイコンを並べた入り口の画面。中身は `home` という名前の、自動で作るレイヤー |
| **HOME** | ホーム画面に戻るソフトキー（`home.soft_key`、既定 `home`） |
| **状態の帯**（`status_bar`） | 画面の上の細い帯。レイヤーの名前、時刻、電池、PC とのつながり、マウスの形、最後の同期 |
| **レイヤーの札**（badge） | 状態の帯を出さないとき、右上に出す今のレイヤーの名前。入り方で色が変わる |
| **上書き**（overrides、`overrides.json`） | Brain の設定のアプリで変えた値。設定ファイルを書き換えずに別のファイルに置き、設定ファイルの値に重ねる |
| **プロファイル**（`profiles`） | PC ごとの設定。つないだ PC が名乗った名前で選び、設定ファイルの値に重ねる |
| **効いている設定** | 設定ファイルにプロファイルと上書きを重ねたもの。デーモンが実際に使う（`configStore.cfg`） |
| **設定ファイル**（`/etc/lefthand/config.yaml`） | 人が書く設定。`.prev` は 1 つ前の版 |
| **データの置き場所**（`/var/lib/lefthand`、`-data-dir`） | Todo、メモ、写真など、Brain が持つデータ |
| **取り直せるもの** | 予定、天気、テキストなど、PC から送り直せるもの。バックアップに入れない |
| **係**（service） | ある種類のデータや機能を受け持つ部品（`TodoService`、`CalendarService`、`Dimmer` など）。保存や通知を自分で行う |
| **学習モード**（`subscribe_input` の `suppress`） | 設定 GUI が、押したキーやタッチを PC に送らずに知らせてもらう状態。割り当てるキーを、実際に押して選ぶのに使う |
| **端末モード**（`terminal`） | Brain の画面とキーボードを、PC か Brain 自身のログインの端末にする |
| **文字を入れる欄**（`input`、`Prompt`） | 画面の下に開く 1 行の入力欄。Todo を足す、時刻を合わせる、アプリの入力 |
| **知らせ**（notice） | 画面の下に数秒出す文（「PC につながっていません」など） |
| **自動減光**（`backlight`） | 触らなければ画面を暗くし、さらに消す |
| **フォトフレーム**（`photo`、`backlight.photo`） | 暗くする代わりに、写真を順に出す |
| **ふた**（`lid`） | 本体を閉じたとき（SW_LID）と、画面を裏返したタブレットの形（SW_TABLET_MODE） |
| **オフライン**、**PC から外したとき**（`offline`） | PC と通信していない状態（電源だけ、外れている）。PC に送るものを休みにする |
| **PCなし** | オフラインのあいだ、PC に送るセルや PC から受け取るタイルに出す札 |
| **USB の形**（`usb_mode`） | HID の形。「キーボードだけ」（ブートキーボード、起動したとき）か「キーボードとマウス」 |
| **USB のネットワークの方式**（`NET_MODE`、`net-mode`） | USB のネットワークのファンクションの種類。NCM（既定）、RNDIS、ECM（このカーネルにはない）。gadget-setup.sh と gadget.env で決める |
| **MAC の形**（`NET_MAC`） | 相手から見た Brain の MAC。pc（既定、8a:15:8b:44:3a:01）か phone（88:15:8b:44:3a:01。Android のイーサネット テザリング用）。本番は phone |
| **USB の準備中**（`preparing`） | 起動したときに、USB の構成（`/dev/hidg0`）がまだできていない状態。PC から外れているときと同じに動き、形の切り替えを断る（フェーズ K6） |
| **段階**（起動を速くする） | contrib/boot/boot-tune.sh で選ぶ、起動を速くする変更のまとまり（1〜3 はサービスを止める、4 は lefthand と USB を早く起動する、5 は表示と udev、6 はジャーナル）。本番は 1〜6 を適用 |
| **読み物の文字**（`-font-dir`） | 読み物の本文の明朝体（`reader-24.lrf.gz`、`reader-32.lrf.gz`）。フェーズ K7 から実行ファイルに埋め込まず、`/usr/local/share/lefthand/` に置く |
| **同期**（`brain-deck sync`） | PC の名前、時刻、予定、天気、RSS、メモ、バックアップをまとめて行うこと |
| **更新の係**、**入れ替えの係**（`lefthand -update-apply`、`lefthand-update`） | 更新、再起動、復元のときに、デーモンの代わりにサービスを止めて入れ替えるもの |
| **更新のファイル**（`*.update.tar.gz`） | `tools/mkupdate` が作る、lefthand と gadget-setup.sh と manifest.json の組 |
| **フェーズ** | 作業の区切り（1〜5、A〜F、P1〜P3、R〜R3、G〜J、K1〜K5 など。名前のない追記もある）。REPORT.md に新しいものから順に記録がある |
| **本番** | 作者がふだん使っている Brain の lefthand.service と config/current.yaml |
| **試験のデーモン**（試験のユニット） | 本番を止めて、時間を区切って動かすテスト用の lefthand（README の「テスト」） |

**「ガジェット」には 2 つの意味がある**ので注意：

| 言葉 | 意味 | どこで |
| --- | --- | --- |
| **USB ガジェット** | Brain が USB の「機器の側」になる Linux の仕組み（configfs、`gadget-setup.sh`） | [2. USB の構成](02-usb.md) |
| **gadgets**（コードの名前） | ストップウォッチ、ポモドーロ、カウンター、在席ランプ、プレゼン用タイマーなど、タップで動かす小さなウィジェット（gadgets.go、gadgetwidget.go、`GadgetService`、`widgets.json`） | [6. ウィジェットとアプリ](06-widgets.md) |

## Linux、USB、端末の言葉

| 言葉 | 意味 |
| --- | --- |
| **Brainux** | Sharp Brain で動く Linux のディストリビューション（Debian ベース） |
| **デーモン** | 裏で動き続けるプログラム |
| **systemd、ユニット** | Linux のサービスの起動と停止を受け持つ仕組みと、その設定ファイル（`*.service`）。**drop-in** は、既存のユニットの一部を上書きする追加の設定ファイル（`*.service.d/*.conf`） |
| **udev** | 機器がつながったときに規則を当てる仕組み（PC 側の contrib/udev） |
| **evdev** | Linux の入力イベントの仕組み（`/dev/input/eventN`）。種類（EV_KEY、EV_ABS、EV_SW、EV_SYN）、コード、値。**grab** は、ほかのプログラムに届かないよう専有すること |
| **HID** | USB のキーボードやマウスの規格。**レポート**は 1 回に送るデータ、**レポートディスクリプタ**はその形を知らせる表、**レポート ID** は 1 つの HID に複数の機器を入れるための番号 |
| **ブートキーボード** | BIOS や UEFI でも使える、決まった 8 バイトの形のキーボード |
| **NCM** | USB のネットワーク（Ethernet）。Brain の usb0 |
| **ACM** | USB のシリアル（CDC-ACM）。Brain 側は `/dev/ttyGS0`、`/dev/ttyGS1`、PC 側は `/dev/ttyACM0`、`/dev/ttyACM1` |
| **configfs** | `/sys/kernel/config` の下に、ディレクトリとファイルで設定を作る仕組み。USB ガジェットの組み立てに使う |
| **UDC** | USB のデバイスコントローラ（`ci_hdrc.0`）。ガジェットを付ける（bind）、外す（unbind） |
| **エンドポイント** | USB の通り道。IN は機器から PC へ。Brain のコントローラは IN が 7 本 |
| **リモートウェイクアップ** | スリープ中の PC を USB の機器から起こすこと |
| **フレームバッファ** | 画面の画素を並べたメモリ（`/dev/fb0`）。**RGB565** は 1 画素 2 バイトの色の形 |
| **VT**（仮想端末） | Linux のコンソールの画面（tty1〜）。1 つだけが表示される |
| **TTY、シリアル** | 文字をやりとりする端末の装置。**生のモード**（raw）は、エコーや行の編集をしない設定 |
| **PTY**（疑似端末） | プログラムに端末につながっていると思わせる仕組み（親 ptmx と子 pts） |
| **getty、agetty** | 端末にログイン画面を出すプログラム |
| **制御シーケンス** | 端末の画面を操作する ESC で始まる文字の並び（カーソル、色、問い合わせ）。**OSC** はその一種 |
| **TIOCEXCL** | シリアルを排他にする ioctl。開いているあいだ、ほかの open は EBUSY |
| **flock** | ファイルのロック（brain-deck どうしの順番待ち） |
| **ioctl** | デバイスに命令を送るシステムコール |
| **mmap** | ファイルやデバイスをメモリとして読み書きする仕組み |
| **`/dev/mem`** | 物理メモリ（ハードウェアのレジスタ）を読み書きする装置。RTC と電源のレジスタを読むのに使う |
| **LRADC** | i.MX28 の AD 変換。電池の電圧（ch7）と USB の 5V（ch15）を読む |
| **RTC** | 電源を切っても時を数える時計 |
| **ulimit、rlimit** | プロセスが使えるもの（メモリ、CPU の時間、ファイル、プロセスの数）の上限 |
| **nice** | プロセスの優先度（大きいほど後回し） |
| **cgroup** | プロセスのまとまりに上限を掛ける仕組み。Brain では使えない（コントローラーが無効） |
| **uim-fep、Anthy** | 端末の中で動く日本語入力と、かな漢字変換 |

## Go の言葉

| 言葉 | 意味 |
| --- | --- |
| **goroutine** | 軽いスレッド。`go f()` で始める |
| **チャネル**（chan） | goroutine のあいだで値を渡す管 |
| **`sync.Mutex`**（ロック） | 同時に 1 つの goroutine だけが触れるようにする仕組み。持ったまま同じロックを取ろうとすると止まる（デッドロック） |
| **atomic** | ロックなしで安全に読み書きできる値 |
| **`go:embed`** | ファイルを実行ファイルに埋め込む指示（フォント、ヘルプ） |
| **`package main`** | 1 つの実行ファイルになるパッケージ。リポジトリの直下の `.go` はすべてこれ |
| **`-ldflags "-X main.version=…"`** | ビルドのときに変数の値を入れる。版の文字列に使う |
| **GOMAXPROCS、GC、GOGC** | 同時に動かす OS のスレッドの数、ゴミ集め（使わなくなったメモリを空ける）、その頻度 |
